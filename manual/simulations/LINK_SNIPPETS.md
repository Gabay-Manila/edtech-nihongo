# Simulation Case Study — Link Snippets for the Manual Portal

Assumes the 12 simulation HTML files are placed at: **/manual/simulations/{id}.html**
(e.g. `/manual/simulations/starter-1.html`).

For each set, paste the matching snippet near the end of that set's `en: { html: `...` }` block
(and optionally the `ja: { html: `...` }` block too — the JA snippet still links to the English page,
since the simulations are English-only).

## Starter Set 1  `(id: starter-1)`

**Add to the `en` block:**
```html
<div class="doc-h2">🎭 Simulation Case Study</div>
<p class="doc-p">
  See a full Teacher AI × Student AI dialogue for this set in action:
  <a href="/manual/simulations/starter-1.html" target="_blank">▶ View Simulation Case Study</a>
</p>
```

**Add to the `ja` block (optional, links to the same English page):**
```html
<div class="doc-h2">🎭 シミュレーション教材</div>
```
